4. ICON FONTS & VECTOR BADGES (ZELDA MAPS & CUSTOM SVGS)
--------------------------------------------------------
- Component: The desktop companion interface and native in-game mod render category
  badges and UI icons.
- Asset Handling: Derived from Zelda Maps UI icon fonts and stylesheets
  (`data/icons/icons.css`) and custom SVG vector badges (e.g. `data/icons/HeartPiece.svg`).
  These are compiled into binary icon atlas packages (`icons.znicons`) at build
  time for local map/HUD rendering in the mod RomFS, and bundled with the desktop
  companion frontend.
